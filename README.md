ABOUT THE CHALLENGE

HACKSPHERE 2026 is the premier international-scale hackathon of Computer Science Atmosphere (COMPSPHERE), organized by President University Faculty Association Computer Science. This year, we invite visionary minds to explore the "Web3 Frontier" The challenge is to build decentralized solutions that leverage blockchain, advanced data security, and transparent architectures to solve real-world industrial problems.

This is a Two-Phase Hybrid competition:

Phase 1 (The Filtering): A 100% conceptual online phase where teams submit a strategic Proposal Idea.
Phase 2 (The Execution): The elite Top 30 teams will engage in a high-intensity 24-hour coding marathon either on-site at President University or virtually for international

WHAT TO BUILD

Participants are challenged to build a Minimum Viable Product (MVP) that addresses a specific industry problem using Web3 foundations (e.g., blockchain, smart contracts, or decentralized storage). You are free to build web-based, mobile, or platform-integrated solutions. Optional stacks like AI or IoT are encouraged as long as the core Web3 features are functional.

WHAT TO SUBMIT

Phase 1 (Required for All): A Proposal Idea Document in PDF format (max 10MB). To ensure your proposal is eligible for judging, you must download and use the [Official Proposal Idea Template](*link proposal). Submissions that do not follow the mandatory anatomy provided in this template will be disqualified.
Phase 2 (Required for Finalists):
Public Repository Link: GitHub or GitLab link for code audit to verify the 24-hour development period.
Presentation Slides: A maximum of 10 slides in PDF or PPT format.
Live Deployment Link (Optional): A URL to a hosted version (Cloud/Testnet/Vercel/Netlify) to earn bonus points.
